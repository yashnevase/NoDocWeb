NoDoc is a free local-first PDF manager and editor for Windows and macOS. Edit, organize, and manage PDFs directly on your computer — no cloud, no accounts.

This repository holds the landing page and showcase for NoDoc.

## Features

- **3D Document Showcase:** Interactive procedural 3D model of the NoDoc document using Three.js and React Three Fiber.
- **Scroll Animations:** GSAP-driven scroll and interaction animations.
- **Offline First:** Emphasizing the local and secure nature of NoDoc.
- **Cross Platform:** Links for Windows and macOS.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
